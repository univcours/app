# NovaGrid — Open in Android Studio (Windows)

The Android native project is generated by Capacitor 8 and is **not checked into Git**. Use one of the two options below. The Android package name is `com.novagrid.cosmicpuzzle`.

## Recommended — link Android Studio to GitHub (two-way Git)

**Do not start from the downloaded Android Studio ZIP** if you want GitHub synchronization: ZIP has no repository history or `.git` metadata. Clone the source repository instead.

1. Install [Git for Windows](https://git-scm.com/downloads/win), [Node.js 22+](https://nodejs.org/), and Android Studio with Android SDK. Open Android Studio.
2. Choose **Get from VCS** (or **File → New → Project from Version Control**).
3. Repository URL: `https://github.com/univcours/app.git`. Choose a local destination such as `C:\\Projects\\NovaGridRepo` and click **Clone**.
4. Because the default branch is `master`, switch to **Remote Branches → origin/novagrid-mvp → Checkout** from the Git branch menu. Alternatively, open the IDE Terminal at the cloned repository root and run:
   ```powershell
   git fetch origin novagrid-mvp
   git switch --track origin/novagrid-mvp
   ```
5. In File Explorer open the cloned `novagrid` folder and double-click `setup-android-studio.cmd`. It installs the dependencies, builds the web files, creates the native Android project and opens it in Android Studio. **Or** run the following commands in Android Studio Terminal from the clone root:
   ```powershell
   cd novagrid
   npm install
   npm run build
   npx cap add android
   npx cap open android
   ```
6. Wait for Gradle Sync, connect the phone with USB debugging (or use an emulator), select the `app` run target, and click **Run ▶**.
7. To fetch changes I publish, double-click **`update-from-github.cmd`** inside the cloned `novagrid` folder: it safely performs `git pull --ff-only`, builds the current web files, and synchronizes Capacitor Android. Alternatively use **Git → Pull** and then `npm run android:sync` manually. To publish your own edits in `novagrid/web`, use **Git → Commit** and **Git → Push** (or the Git tool window).

**Current source-control limitation:** `novagrid/android/` is generated locally and ignored in Git, so *native Android Gradle/layout changes in that folder will NOT be pushed*. Do not make important native edits there without first changing the repo's native-file versioning strategy. The GitHub-tracked game source is `novagrid/web/` and the configuration files.

## Option A — quickest way (no Node.js needed)

1. Visit the [NovaGrid Android build runs](https://github.com/univcours/app/actions/workflows/novagrid-build.yml) and open the latest **successful** run from branch `novagrid-mvp`.
2. Scroll to **Artifacts** and download **`novagrid-android-studio`** (GitHub login may be required).
3. Extract the ZIP to a regular folder, e.g. `C:\\Projects\\NovaGrid-Android`. Do not open the ZIP directly.
4. Launch **Android Studio** → **Open** → select the extracted folder containing `settings.gradle` / `settings.gradle.kts` (the `android` Gradle project root).
5. Wait for **Gradle Sync** to finish. Install missing Android SDK platform/build tools from prompts if needed.
6. For a physical Android phone: enable **Developer options** (Settings → About phone → tap **Build number** 7 times), then **USB debugging** under Developer options. Plug the phone in with a data-capable USB cable, unlock it, and approve the **Allow USB debugging** prompt.
7. At the top of Android Studio select the connected phone and `app` configuration, then click **Run ▶**. The debug build is installed and launched on the phone.

A local emulator is an alternative: **Tools → Device Manager → Create Virtual Device**, then select it in Run.

**Important:** The uploaded Android Studio project is a snapshot of that workflow run. It is not automatically synchronized when you change the web app source on GitHub.

## Option B — edit the app while connected to GitHub

Requirements: Android Studio (Capacitor 8 needs Android Studio **2025.2.1+**), Android SDK, Git and Node.js 22+, with a terminal / PowerShell.

Clone the correct branch (not the repo default `master`):

```powershell
git clone --branch novagrid-mvp --single-branch https://github.com/univcours/app.git
cd app\novagrid
npm install
npm run build
npx cap add android
npx cap open android
```

If `npx cap open android` cannot locate Android Studio, manually open the `app/novagrid/android` folder in Android Studio.

After editing any file in `web/`, synchronize it with the Android project:

```powershell
npm run android:sync
```

Then click Run again in Android Studio.

The repository's `.gitignore` excludes the generated `android/` project by design. When switching machines, either repeat Option B or use the fresh ZIP artifact from Option A.

## Troubleshooting

- **Device not visible:** use a USB data cable, accept the RSA authorization dialog, enable USB debugging and check **Tools → Troubleshoot Device Connections**.
- **Gradle/JDK errors:** select the **Gradle JDK** offered by Android Studio, ideally JDK 21. Let the IDE download needed Android SDK packages (including API 36).
- **Changes not visible:** always run `npm run android:sync` after updating `web/` files.
- **Do not use the AAB for local installs:** choose Run in Android Studio or use the debug APK artifact for phone testing.
- **For Play Store:** debug APK and unsigned release AAB are not publishable releases. Release signing and Play Console policy tasks are still separate.

## Android Gradle Plugin 9: unsupported legacy ProGuard config

If Android Studio reports `getDefaultProguardFile('proguard-android.txt')` is no longer supported (often `android/app/build.gradle` around line 22), the generated Capacitor Android project still uses an old default setting. This is **not** a gameplay issue.

From `novagrid/` run `npm run android:gradle-fix`, or simply `npm run android:sync` after pulling latest GitHub changes; both now automatically migrate the generated Gradle file to `proguard-android-optimize.txt`. The change is idempotent and does not touch other ProGuard rules. Then click **File → Sync Project with Gradle Files**, select the `app` configuration and run the game.

If necessary, you may manually replace the exact string in `android/app/build.gradle`. The Android folder is Git-ignored, so the tracked sync script ensures the correction is re-applied after future project generation.
