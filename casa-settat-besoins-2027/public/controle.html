Importation et suivi des codes-barres

Importation des codes-barres

Sélectionnez l’opération ci-dessus, puis choisissez le type de fichier. Les colonnes « CAB » et « NomAgence » (ou « Nom agence ») sont reconnues automatiquement dans Excel ; le fichier global est réparti entre les agences et le fichier individuel ne modifie que l’agence choisie.

L’opération choisie en haut de page est conservée. Si le nom du fichier indique une autre opération, l’importation est refusée pour éviter les erreurs.

Important : dans Excel, formatez la colonne des codes-barres en « Texte » pour conserver les zéros initiaux et éviter la notation scientifique. Après une importation réussie, le fichier est automatiquement retiré de cette zone ; seules les données des codes sont enregistrées, et non le fichier Excel original.

Agences absentes de la liste principale

Une agence doit exister dans la liste officielle pour recevoir des CAB. Ajoutez les agences manquantes ci-dessous ou dans « Liste principale des agences ». Les lignes non reconnues ne seront pas importées.

Liste principale des agences

Ajoutez une agence officielle. Les quatre opérations partageront cette liste, sans rattachement à une autre agence.

Associations des agences

Retrouvez et modifiez à tout moment les correspondances entre les noms du fichier Excel et les agences officielles, pour les quatre opérations.

Une association personnalisée est prioritaire sur le nom d’agence de la liste principale. Les modifications concernent la répartition lors du prochain import Excel ; pour déplacer les CAB déjà enregistrés, réimportez le fichier de l’opération.

Comptes des agents

Attribuez un identifiant et un mot de passe à une ou plusieurs agences. Le même identifiant ouvre toutes les agences qui lui sont attribuées.

Pour attribuer plusieurs agences au même agent, enregistrez chaque agence avec le même identifiant. Le mot de passe existant est partagé. Pour le modifier, sélectionnez « Changer pour toutes ses agences ». Les mots de passe ne sont jamais affichés.

Ouverture et fermeture du site

Fermez l’accès aux utilisateurs (codes-barres et formulaires) sans effacer les données. Votre espace coordinateur reste disponible pour rouvrir le service.

Le lien GitHub Pages reste consultable, mais le serveur bloque les fonctionnalités utilisateur pendant la fermeture.
