# Open NovaGrid directly in Godot on Windows

1. Extract the ZIP. Keep project.godot, scripts, scenes and other folders together.
2. Double-click OPEN-NOVAGRID-GODOT.cmd in the same folder as project.godot.
3. The helper locates Godot 4.5.1 Standard and opens the complete native project in the editor.
4. Press F5 to play, or edit scenes/Main.tscn and scripts/Main.gd.

If Godot is missing, download the Windows Standard editor from https://godotengine.org/download/archive/4.5.1-stable/ and unzip the EXE into Downloads. Retry the helper.

No APK/ADB/Android Studio needed to edit and run on PC. This never modifies the original Play Store installation. The optional -Play flag to scripts/open-in-godot.ps1 runs the game without the editor.
